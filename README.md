# 🔥 Fire and Smoke Detection with Alarm Using Arduino

## 📌 Project Overview
This project is an Arduino-based fire and smoke detection system designed to detect fire and smoke in real time using a Flame Sensor and an MQ-2 Smoke Sensor. When fire or excessive smoke is detected, the system activates a buzzer alarm and displays warning messages on a 16x2 I2C LCD. This project can be used in homes, laboratories, offices, and small industries to improve safety.

## 🎯 Objectives
- Detect fire using a flame sensor.
- Detect smoke using an MQ-2 gas sensor.
- Alert users with a buzzer.
- Display system status on a 16x2 I2C LCD.
- Provide a low-cost fire safety solution.

## ⚙️ Working Principle
1. The Flame Sensor continuously monitors for fire.
2. The MQ-2 Sensor measures smoke concentration.
3. Arduino processes the sensor values.
4. If fire or smoke exceeds the threshold:
   - The buzzer turns ON.
   - A warning message is displayed on the LCD.
5. When the environment is safe, the buzzer turns OFF and the LCD returns to normal status.
